# Energy Consumption and Sustainability Analysis

## Summary
Analysis of energy consumption patterns to identify trends, peak usage
periods, and opportunities for improving energy efficiency and
sustainability.

## Project Structure
- notebooks/energy_consumption_analysis.ipynb — Main analysis notebook
- data/ — Raw and processed datasets
- images/ — Visualizations and charts

## How to Run
1. Download the dataset from the link in data/README.md
2. Place it in the data/ folder
3. Open notebooks/energy_consumption_analysis.ipynb in Google Colab
4. Run all cells

## Tools Used
- Python, pandas, NumPy
- SQL
- Matplotlib, Seaborn
- Tableau Public / Google Data Studio
